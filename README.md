# カンペ

発表の原稿を、開始からの経過時間に合わせて自動で切り替えて表示するカンペサイト。

HTML1枚だけで動く。サーバー不要、アカウント不要、通信なし。台本は開いた人の端末にだけ保存され、外に出ない。

URLを配れば、受け取った人はそれぞれ自分の台本を入れて自分の画面で使える。台本が他の人に見えることはない。

---

## 使い方

### 1. 台本を入れる

「編集」を押して、項目ごとに **開始からの経過時間** と **その時間に読む内容** を入力する。

| 入力例 | 解釈 |
|---|---|
| `3:30` | 3分30秒 |
| `5` | 5分（数字だけなら分） |
| `1:02:30` | 1時間2分30秒 |
| `90秒` | 90秒 |
| `3分15秒` | 3分15秒 |

内容は台本そのままでも、箇条書きのメモでもいい。改行はそのまま表示される。

### 2. 表示して進める

「表示へ戻る」→「開始」でカウントが始まる。指定した時間になると、その項目が自動で表示される。

| 操作 | 動き |
|---|---|
| 開始 / 一時停止 | タイマーの開始・停止。開始すると集中モードに入る |
| 戻す | 経過時間を 00:00 に戻す |
| ◀ ▶ | 前後の項目へ移動。タイマーもその項目の時刻へ移動する |
| ⤢ | 集中モードの切り替え（カードのタップでも同じ） |
| A− / A+ | 文字サイズの上限を調整 |
| 上部のリボン | タップした位置の時間へ移動 |

キーボード：`Space` 開始/一時停止、`→` 次の項目、`←` 前の項目。

### 3. 本番中の見え方

- 台本はカードに収まる最大の文字サイズへ自動調整される。スクロールは起きない
- 下段の NEXT に次の項目と残り時間が出る。**残り30秒で赤く点滅する**
- 開始すると操作ボタンが畳まれ、台本の表示面積が広がる。対応端末ではフルスクリーンにもなる
- スリープ抑止に対応した端末では、表示中に画面が消えない

## 台本の取り込み

手元の台本をAIに変換させて、まとめて流し込める。編集画面の「台本を取り込む」に貼り付けて、「今の台本に追加」か「全部を置き換え」を押す。

### 変換用プロンプト

> 以下の台本を変換してください。1行につき「開始からの経過時間（分:秒）＋タブ＋その時間に読む内容」の形式。1項目が複数行になる場合、2行目以降は時間を書かずそのまま続けてください。前置きや説明は出力しないでください。

### 読み取れる形

崩れていても、読めた分だけ取り込む方針で作ってある。

**行の形式**

```
0:00	開会のあいさつ
3:30	講師紹介
・経歴
・今日のねらい
```

- 時間のない行は、直前の項目の続きとして扱われる
- 区切りはタブ、スペース、`:`、`|`、`、`、`-`、`/` のいずれでもいい
- `【0:00】オープニング`、`- 0:00: つかみ`、`5分 - 自己紹介` のような書き方も読める
- 全角数字・全角コロン（`０:００`）も読める
- 本文中の `10:00になったら資料を出す` は時間と誤認しない（時間の直後が区切り文字か行末のときだけ時間とみなす）

**JSON**

```json
[
  { "at": "0:00", "text": "開会のあいさつ" },
  { "at": 210,    "text": "講師紹介" }
]
```

- 配列そのままでも、`{"cues": [...]}` のように包まれていてもいい
- 時間のキーは `at` / `time` / `start` / `sec` / `時間` / `開始` などを順に探す
- 本文のキーは `text` / `content` / `body` / `内容` / `台本` などを順に探す
- 前後に説明文や ```` ```json ```` が付いていても、JSON部分を抜き出して読む

**取り込み結果の表示**

```
3件を追加しました／2行は直前の項目に続けました／1行は時間が読めず飛ばしました
```

読めなかった行は捨てられる。取り込んだあとは編集画面に一覧で出るので、足りない分は手で足す。

### 書き出し

「書き出し」で `kanpe.json` としてダウンロードできる。バックアップや、別の端末への移動に使う。「ファイルから読む」で戻せる。

## 配布

`index.html` を1枚置くだけ。GitHub Pages なら、リポジトリのルートに `index.html` を置いて Pages を有効にする。

```
https://<ユーザー名>.github.io/kanpe/
```

配る相手には、URLと変換用プロンプトの2つを渡せばいい。

---

## データの扱い

- 台本と文字サイズの設定は、ブラウザの `localStorage` にキー `kanpe.v1` で保存される
- 保存先は開いた本人の端末。サーバーには何も送らない
- 同じURLを開いた人どうしで台本が共有されることはない
- ブラウザの履歴やサイトデータを消すと、台本も消える。大事な台本は「書き出し」でバックアップしておく
- `localStorage` が使えない環境（一部の埋め込みプレビューなど）では、警告を出したうえでメモリ上だけで動く。タブを閉じると消える

---

## 制限と注意

- タイマーは端末の時計を使うので、複数人で厳密に同期はしない。各自が自分の開始ボタンを押して使う想定
- ▶ で項目を飛ばすと、その項目の予定時刻までタイマーが進む。全体が前倒しになる点に注意
- 台本が長い項目ほど文字が小さくなる。最小13pxでも入りきらない場合だけスクロールする
- フルスクリーンとスリープ抑止は、対応していない端末では静かに無視される

---

## 構成

```
index.html    すべて（HTML / CSS / JavaScript）
```

外部ライブラリなし。ビルド不要。ファイルを直接開いても動く。

### 主な処理

| 関数 | 役割 |
|---|---|
| `toSec()` | 時間表記を秒に変換。読めなければ `null` |
| `tryJSON()` / `tryLines()` | 取り込みの解釈。JSONを先に試し、だめなら行として読む |
| `fitText()` | 二分探索でカードに収まる最大の文字サイズを決める |
| `render()` | 250msごとに時計・リボン・カード・NEXTを更新 |
| `setFocus()` | 集中モードとフルスクリーンの切り替え |

### 見た目の調整

`:root` のCSS変数を変えると全体の色が変わる。

| 変数 | 用途 |
|---|---|
| `--stage` / `--panel` | 背景と操作パネル |
| `--paper` / `--paper-ink` | 台本カードの紙色と文字色 |
| `--go` | 進行中を示す色 |
| `--standby` | 残り30秒・警告の色 |
| `--mincho` / `--gothic` / `--mono` | 台本 / UI / 数字の書体 |
