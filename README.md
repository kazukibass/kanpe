# Kanpe

発表台本を、開始からの経過時間に合わせて自動表示するブラウザ用カンペです。

`index.html` だけで動作し、サーバー・アカウント・外部ライブラリは不要です。台本や表示設定は使用中のブラウザ内に保存され、外部へ送信されません。スマートフォンでは手軽なカンペとして、PCでは練習・発表用の大きな表示として利用できます。

---

## 主な機能

- 経過時間に連動した台本の自動切り替え
- 現在の見出しを強調表示するタイムライン
- 開始・一時停止・冒頭・前後・終点のプレイヤー操作
- 最後の見出しを終点として自動停止
- 表示画面を大きなメモ帳のように直接編集
- 同時刻の見出しを検出し、発表開始を防ぐ警告
- 台本全体を確認・編集できる一覧画面
- PC・スマートフォン対応のレスポンシブ表示
- ダークモード・ライトモード
- 発表モードと、PC用フルスクリーンの個別切り替え
- 文字数からの読み上げ時間の見積もりと、割当・目標との差分表示
- 話し言葉を除いた配布資料版の書き出し（Markdown・PDF）
- 見出し・要点・話す内容を割り当てたPowerPointたたき台（.pptx）の書き出し
- JSONの読み込み・書き出し
- AI向けのJSON変換プロンプトと台本作成プロンプト

## 基本的な使い方

### 1. 台本を用意する

「一覧」から、各項目の開始時刻と本文を編集します。時刻は発表開始からの経過時間です。

見出しの先頭は、タイムラインでも判別しやすいように番号から始めるのがおすすめです。

```text
01 オープニング
本日はお越しいただきありがとうございます。
```

### 2. 表示する

ロゴを押すと「一覧」と「表示」を行き来できます。スマートフォンではロゴが `K` と表示されます。表示中に大きな台本文字をダブルクリック（スマートフォンではダブルタップ）するか、「編集」を押すと、その場で本文を編集できます。

- `保存`：表示中の編集を確定
- 編集領域の外をクリック／タップ：保存して編集を終了
- `Ctrl/Cmd + Enter`：表示中の編集を確定
- `Esc`：表示中の編集をキャンセル

一覧から移動した場合は一覧の先頭を表示します。表示中の本文を編集中に一覧へ移動した場合のみ、編集中だった項目を一覧で開きます。

### 3. タイマーを操作する

上部のプレイヤーから操作します。

| 操作 | 動き |
|---|---|
| 冒頭 | タイマーを停止して `00:00` に戻す |
| 前へ / 次へ | 前後の見出しへ移動する |
| 再生 / 一時停止 | タイマーを開始・停止する |
| 終点 | 最後の見出しへ移動する |
| タイムライン | 見出しの位置を選んで移動する |

タイムラインは任意の秒数へシークするものではなく、見出しの位置だけを選択できます。現在の見出しは緑で強調され、近接する見出しより前面に表示されます。PCでは見出しの冒頭数文字を表示し、スマートフォンでは `▼` を押すと時刻順の通し番号を確認でき、`×` で閉じられます。

最後の見出しに到達するとタイマーは自動停止します。最後の見出しは、本文を持たない `終了` にしておくことを推奨します。

同じ開始時刻を持つ項目がある場合は警告を表示し、発表モードへの移行を停止します。通常の表示モードでは、その時刻に登録順で先にある項目だけを表示します。一覧で重複時刻を修正すると、警告が消えて発表モードを利用できるようになります。

### 4. 発表で使う

「発表」を押すと、編集用の要素を抑えた発表モードになります。発表モードへの切り替えだけではフルスクリーンになりません。

発表中もPCでは `Kanpe`、スマートフォンでは `K` のロゴを表示しますが、誤操作防止のためロゴから画面を切り替えることはできません。

PCでは発表モード中のみ右下にフルスクリーンボタンが表示されます。画面遷移を避けたい場合は発表モードだけ、画面全体を使いたい場合は追加でフルスクリーンを有効にできます。

対応ブラウザでは、発表中の画面スリープ抑止も行います。

### スマートフォンの操作

- 左上の `K`：表示と一覧を切り替える
- 中央のプレイヤー：冒頭・前・再生／停止・次・終点
- 右側の `発表`：発表モードへ切り替える
- 右上の三本線：編集・文字サイズ・配色・配布資料とPowerPointの出力・AI用プロンプト
- 台本文字のダブルタップ：表示したまま本文を編集する

カンペ表示中は、台本文字以外の連続タップによる意図しない画面拡大を抑えます。通常のピンチズームは利用できます。

## キー操作

| キー | 動き |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` | 前の見出しへ |
| `→` | 次の見出しへ |
| `F` | 発表モードの切り替え |
| `Ctrl/Cmd + Enter` | 表示中の編集を保存 |
| `Esc` | 編集のキャンセル、または開いている小窓を閉じる |

入力欄や表示中の本文を編集している間は、誤操作を避けるため一部のキー操作が無効になります。

## 見出しと要点の書き方

各項目の本文は、次のように読みます。

| 位置 | 扱い |
|---|---|
| 1行目 | 見出し。読み上げには数えない |
| `・` `-` `1.` などで始まる行 | 要点。配布資料へそのまま載る |
| それ以外の行 | 読み上げる話し言葉 |
| `【 】` で囲んだ部分 | 読み上げない指示。時間にも配布資料にも含めない |

```text
02 サービスの特長
・初期費用ゼロ
・最短3日で導入
本日は特に導入までの早さをご紹介します。【画面切替】
```

要点の行がない項目では、本文から自動で要点を抜き出します。段落がひとつなら先頭の3文、段落が分かれていれば各段落の第1文を使います。自動で抜き出した項目には、一覧で「（自動抽出）」と表示されます。

意図した要点を出したい場合は、`・` で始まる行を自分で書いてください。

## 読み上げ時間の見積もり

「一覧」の上部に見積もりが出ます。文字数から読み上げ時間を計算し、実際に割り当てた時間と比べます。

| 表示 | 意味 |
|---|---|
| 台本の終点 | 最後の項目の時刻。タイマーが自動停止する時刻 |
| 読み上げの推定 | 全項目の本文から計算した読み上げ時間の合計 |
| 目標との差 | 推定と、入力した目標時間との差 |
| 時間オーバー | 割当より推定が長い項目の数 |

各項目にも `割当 01:30　推定 01:52　+0:22` のように表示されます。割当は次の項目までの時間です。推定が割当を超えた項目は赤で示されるので、そこだけ本文を削るか、開始時刻をずらして調整します。

- **目標**：`10:00`、`10分`、`90秒`、`10`（分として読む）のいずれでも入力できます。空にすると差分表示を止めます
- **話速**：1分あたりの読み上げ文字数です。既定は300字/分で、100〜900の範囲で変えられます

見出し行と `【 】` の指示は読み上げに数えません。最後の `終了` 項目も0秒として扱います。

目標と話速は台本と一緒に端末へ保存されます。

## 配布資料版の出力

メニュー（PCは右上の三本線、スマートフォンも同じ）から、話し言葉を除いた配布資料を作れます。見出しと要点だけが残り、読み上げ本文・`【 】` の指示・最後の `終了` 項目は載りません。

- **配布資料をMarkdownで書き出す**：内容を小窓で確認・編集してから `.md` としてダウンロードします
- **配布資料を印刷／PDFで保存**：ブラウザの印刷画面を開きます。出力先に「PDFとして保存」を選ぶとPDFになります

PDFはブラウザの印刷機能を使うため、日本語フォントの埋め込みや余白は各ブラウザの設定に従います。印刷時はカンペの操作画面を隠し、配布資料だけを出力します。

## PowerPointのたたき台

同じメニューの「PowerPointのたたき台を書き出す」から `.pptx` を作れます。各項目が1枚のスライドになり、次のように割り当てられます。

| 台本 | PowerPoint |
|---|---|
| 見出し（1行目） | スライドタイトル |
| 要点 | 本文の箇条書き |
| 読み上げる話し言葉 | 発表者ノート |

最後の `終了` 項目はスライドになりません。レイアウトは16:9の「タイトルと箇条書き」1種類だけです。配色やフォントを整えるのはPowerPoint側で行う前提の、あくまで下書きです。

外部ライブラリを使わずに生成しています。`.pptx` はZIPとXMLの組み合わせなので、ZIPの組み立てからOOXMLの各パートまでを `index.html` 内で作っています。圧縮率は不要なので、deflateの非圧縮ブロックだけで有効なdeflateストリームを組んでいます。

Microsoft PowerPoint、LibreOffice Impress で開けることを確認しています。

## JSONの読み込み・書き出し

台本は次の形式で扱います。

```json
{
  "title": "発表台本",
  "cues": [
    {
      "at": 0,
      "text": "01 オープニング\n本日はお越しいただきありがとうございます。"
    },
    {
      "at": 180,
      "text": "02 デモ\nここで画面を切り替えます。"
    },
    {
      "at": 600,
      "text": "03 終了"
    }
  ]
}
```

- `title`：台本名
- `cues`：見出しの配列
- `at`：発表開始からの秒数
- `text`：見出しと本文
- `at` は小さい順に並べる
- 最後の見出しの `at` がタイムラインの終点になる

設定画面からJSONファイルを読み込み・ダウンロードできます。大切な台本は定期的に書き出して保管してください。

## AIで台本を作る

設定画面には次の文書が用意されています。

- `JSON変換プロンプト`：既存の台本をKanpe用JSONへ変換する
- `台本作成プロンプト`：題材や時間配分からKanpe用台本を作る
- `2種類を一括保存`：両方をまとめてダウンロードする

個別の文書は内容を小窓で確認・編集してからダウンロードできます。

プロンプトでは、各見出しを `01`、`02` のような番号から始め、先頭の短いサマリーをタイムラインのラベルとして使う構成を推奨しています。また、指定された発表時間または推定した終了時刻に、本文を持たない最後の `終了` 見出しを追加するよう指示しています。

## データとプライバシー

- 台本と設定はブラウザの `localStorage` に保存される
- データは使用している端末から外部へ送信されない
- 同じURLを開いた利用者同士で台本は共有されない
- ブラウザのサイトデータを削除すると保存内容も消える
- `localStorage` が使えない環境では、そのタブを閉じるまでの一時保存になる

端末を変える場合やバックアップを取る場合は、JSONを書き出して移動してください。

## 配布

`index.html` をWebサーバーへ置くだけで配布できます。GitHub Pagesを使う場合は、リポジトリのルートに配置してPagesを有効にします。

```text
https://<ユーザー名>.github.io/kanpe/
```

ファイルを直接ブラウザで開いて使うこともできます。

---

## 制限と注意

- タイマーは各端末の時計で動作し、複数端末間では同期しない
- 前後の見出しへ移動すると、タイマーもその見出しの予定時刻へ移動する
- 本文が長いほど、画面内へ収めるため文字が小さくなる
- フルスクリーンやスリープ抑止は、非対応ブラウザでは利用できない
- iPhoneのSafariでは入力時の自動ズームを抑える調整を行っているが、OSやブラウザの設定によって挙動が異なる場合がある
